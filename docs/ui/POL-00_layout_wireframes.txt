POL-00 target layout wireframes (ASCII)
======================================

----------------------
+------------------------------------------------------------------+
| MergeTool   [File Compare] [Folder] [3-Way Folder] [3-Way]       |  <- global launch (single row)
+------------------------------------------------------------------+
| Recents [v] Open | Pinned [v] Open | Pin | Clear | Reset         |  <- session bar (collapsible in target)
+------------------------------------------------------------------+
| [ left.txt <-> right.txt                              x ]  tabs  |

|                                                                  |
|                     WORKSPACE CONTENT (dominant)                 |
|                                                                  |
+------------------------------------------------------------------+
| Idle | [==== busy ====] Cancel                                   |  <- status
+------------------------------------------------------------------+
