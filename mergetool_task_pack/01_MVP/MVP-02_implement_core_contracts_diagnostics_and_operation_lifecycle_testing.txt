# MVP-02 Testing Task
## Headline
Verify: Implement core contracts, diagnostics, and cancellable operation lifecycle


## Mandatory baseline checks
Run from a clean working tree when possible:
```powershell
dotnet restore
dotnet build -c Debug
dotnet test -c Debug
dotnet build -c Release
dotnet test -c Release
```

Inspect `git diff` and `docs/DEPENDENCIES.md`. Confirm no unexpected package, architecture, or scope change was introduced.



## Tester instructions
- Confirm Core/Application compile without WPF references.
- Run unit tests covering request ordering and cancellation behavior.
- Inspect the operation-lifecycle document for concrete rules about stale results and cancellation.
- Verify that cancellation is represented as a safe result/state, not an unhandled exception.
- Confirm no new third-party dependency was added to solve a small core-contract problem.

## Failure conditions
Fail if stale results cannot be identified, cancellation semantics are vague, diagnostics are UI-bound, or the task introduces a disproportionate framework.

Create `docs/task-reports/MVP-02_testing.md` with verdict, evidence, defects, and proceed/fix recommendation. Follow `00_DELIVERY_AND_TEST_PROTOCOL.txt` exactly.
