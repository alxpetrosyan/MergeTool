# ADV-01 Development Task
## Headline
Add bounded intraline diff rendering


## Objective
Show changed spans inside modified line pairs without degrading correctness or performance.

## Developer instructions
Extend Text comparison results with optional immutable `InlineDiffSegment` data for `Modified` line pairs only. Add a bounded word/character algorithm with documented limits for line length and work budget; when exceeded, return a `WholeLineFallback` marker instead of freezing.

Keep inline calculation optional in `TextComparisonOptions`. Render semantic inline spans using AvalonEdit adapters without altering document text. Ensure stale comparisons invalidate inline render results too.

Add exact tests for replacement, insertion, deletion, whitespace-significant case, Unicode surrogate-safe handling, and long-line fallback.

## Drift prevention
No semantic code diff, syntax-aware parsing, moved-line detection, or per-character UI editor mutation.

## Mandatory completion evidence
- Add/update automated tests for the change.
- Run Debug and Release build/test commands.
- Create the required development report under `docs/task-reports/`.
- Do not start the next task until the paired testing task has passed.
