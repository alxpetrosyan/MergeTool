# ADV-02 Development Task
## Headline
Add comparison rules with projection-safe normalization


## Objective
Reduce noise while preserving the original text used for display and merge.

## Developer instructions
Add explicit options: whitespace modes, ignore case, ignore empty lines, ignored-line regex, ignored-block start/end regex. Implement a comparison projection that maps normalized comparison lines back to original source ranges. Invalid regex returns diagnostics; never change editable document text.

Expose a simple options panel and active-rule badge. Recompare explicitly; do not apply rule changes invisibly. Merge always copies original source text, never normalized values.

Tests must cover mapping, invalid regex, whitespace/case behavior, block boundaries, and merge source integrity.

## Drift prevention
No comment parser, global profile system, auto-save of rules, or regex replacement editor.

## Mandatory completion evidence
- Add/update automated tests for the change.
- Run Debug and Release build/test commands.
- Create the required development report under `docs/task-reports/`.
- Do not start the next task until the paired testing task has passed.
