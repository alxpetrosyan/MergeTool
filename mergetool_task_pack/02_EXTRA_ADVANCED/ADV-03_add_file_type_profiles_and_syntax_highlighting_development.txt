# ADV-03 Development Task
## Headline
Add data-driven file-type profiles and syntax highlighting


## Objective
Improve readability for common developer files without coupling parser behavior to core comparison.

## Developer instructions
Implement profile matching by extension/file mask in a non-WPF project. Profiles: Plain Text, Delphi/Pascal, C#, SQL, XML, JSON, HTML, CSS, JavaScript, TypeScript, Markdown, INI/config. Profile may define tab size and default comparison options. Keep syntax-renderer mapping in WPF/AvalonEdit adapters.

Automatic detection must be visible and manual per-tab override must be possible. Changing a profile prompts/requires recompare only when comparison options differ.

## Drift prevention
No language server, formatter, semantic parser, package-heavy syntax stack, or project-wide persistent preference system.

## Mandatory completion evidence
- Add/update automated tests for the change.
- Run Debug and Release build/test commands.
- Create the required development report under `docs/task-reports/`.
- Do not start the next task until the paired testing task has passed.
