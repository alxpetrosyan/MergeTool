# ADV-05 Development Task
## Headline
Add search, go-to-line, and difference list


## Objective
Provide fast inspection/navigation for larger text comparisons.

## Developer instructions
Implement non-UI search service with literal/regex, case/whole-word options, pane selection, changed-lines-only mode, cancellation for large input, and invalid-regex diagnostics. Add go-to-line with source-line bounds. Add difference list model synchronized with current diff selection.

UI adds a focused search bar/panel and a difference list. Search must not silently change comparison results.

## Drift prevention
No replace-all, multi-file search, external code indexer, or unbounded regex execution without cancellation/timeouts.

## Mandatory completion evidence
- Add/update automated tests for the change.
- Run Debug and Release build/test commands.
- Create the required development report under `docs/task-reports/`.
- Do not start the next task until the paired testing task has passed.
