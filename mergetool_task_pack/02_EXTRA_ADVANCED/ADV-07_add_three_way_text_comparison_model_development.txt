# ADV-07 Development Task
## Headline
Add 3-way text comparison model and inspection UI


## Objective
Compare left/base/right text safely before any output merge behavior.

## Developer instructions
Implement a 3-way model built from two base-relative comparisons. Classify base regions as unchanged, left-only change, right-only change, same change on both sides, or overlapping/divergent change. Preserve base/left/right source ranges and document revisions. Do not infer conflict resolution automatically.

Add 3-pane inspection workspace with clear labels. Keep all panes source documents; no merge output pane yet. Reuse file loading/session/cancellation conventions.

## Drift prevention
No automatic merge, conflict-marker writing, output file mutation, or repository/VCS semantics.

## Mandatory completion evidence
- Add/update automated tests for the change.
- Run Debug and Release build/test commands.
- Create the required development report under `docs/task-reports/`.
- Do not start the next task until the paired testing task has passed.
