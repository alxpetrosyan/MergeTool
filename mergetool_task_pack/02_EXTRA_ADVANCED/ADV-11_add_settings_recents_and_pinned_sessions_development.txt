# ADV-11 Development Task
## Headline
Add settings, recents, and pinned comparison entries


## Objective
Add lightweight local persistence without making settings a hidden source of behavior.

## Developer instructions
Implement versioned JSON settings with atomic write, corruption fallback/diagnostics, recent file/folder comparisons, and pinned entries. Store paths and selected user options only; do not store file contents, file hashes, credentials, or comparison archives. Settings are opt-in/visible and resettable.

## Drift prevention
No cloud sync, account, telemetry, stored secrets, or opaque binary settings store.

## Mandatory completion evidence
- Add/update automated tests for the change.
- Run Debug and Release build/test commands.
- Create the required development report under `docs/task-reports/`.
- Do not start the next task until the paired testing task has passed.
