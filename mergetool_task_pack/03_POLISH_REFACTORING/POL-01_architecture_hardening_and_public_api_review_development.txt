# POL-01 Development Task
## Headline
Harden architecture and review public APIs


## Objective
Remove accidental coupling and overengineering accumulated across features.

## Developer instructions
Review project references, public APIs, duplicated models, ownership of cancellation/diagnostics, WPF leakage, and lifecycle code. Refactor only with measurable simplification or correctness benefit. Consolidate shared primitives where duplication is real; do not introduce a framework to make the solution look abstract.

Document significant decisions in `docs/architecture/` and add characterization tests before risky refactors.

## Drift prevention
No new end-user features, wholesale rewrite, plug-in system, or dependency replacement without cause.

## Mandatory completion evidence
- Add/update automated tests for the change.
- Run Debug and Release build/test commands.
- Create the required development report under `docs/task-reports/`.
- Do not start the next task until the paired testing task has passed.
