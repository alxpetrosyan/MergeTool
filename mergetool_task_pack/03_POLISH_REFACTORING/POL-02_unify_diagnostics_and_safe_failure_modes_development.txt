# POL-02 Development Task
## Headline
Unify diagnostics and safe failure modes


## Objective
Ensure user-visible failures are safe, actionable, and consistent across file, folder, parse, save, and operation paths.

## Developer instructions
Normalize diagnostic codes/messages for load, decode, path, permission, save conflict, regex, parse, folder operation, cancellation, and unexpected failures. WPF displays safe summary with optional technical details/copy action. Do not use exceptions for expected large-scan control flow.

Add tests for each expected failure family and ensure error flows preserve last valid comparison/session state.

## Drift prevention
No cloud telemetry, crash-report service, remote logging, or silent error swallowing.

## Mandatory completion evidence
- Add/update automated tests for the change.
- Run Debug and Release build/test commands.
- Create the required development report under `docs/task-reports/`.
- Do not start the next task until the paired testing task has passed.
