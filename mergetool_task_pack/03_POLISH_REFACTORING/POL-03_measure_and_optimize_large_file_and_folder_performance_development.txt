# POL-03 Development Task
## Headline
Measure and optimize large file/folder performance


## Objective
Use measurement to keep the commercial tool responsive under real-world loads.

## Developer instructions
Create repeatable benchmark/smoke scripts for 1 MB/10 MB text, long lines, repeated lines, 1k/10k/50k folder entries, and hash mode where enabled. Measure elapsed time, allocation/memory trends, UI responsiveness, cancellation latency. Optimize only demonstrated bottlenecks: avoid repeated splits/copies, ensure virtualized grids, stream hashes, and keep UI thread free.

Document hardware/environment and practical budgets; do not promise universal timing guarantees.

## Drift prevention
No native rewrite, GPU work, binary compare, or speculative micro-optimizations without measurements.

## Mandatory completion evidence
- Add/update automated tests for the change.
- Run Debug and Release build/test commands.
- Create the required development report under `docs/task-reports/`.
- Do not start the next task until the paired testing task has passed.
