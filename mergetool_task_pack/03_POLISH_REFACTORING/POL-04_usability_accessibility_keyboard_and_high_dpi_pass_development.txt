# POL-04 Development Task
## Headline
Perform usability, accessibility, keyboard, and High-DPI pass


## Objective
Make core workflows comfortable for daily Windows use without adding a customisation product.

## Developer instructions
Standardize shortcuts, command labels/tooltips, focus/tab order, accessible names, dirty/read-only/stale indicators, clear destructive-operation confirmations, and fixed semantic colours with adequate contrast. Verify layout at 100/125/150/200% scaling. Support keyboard use for file compare, merge, folder compare, filtering, and safe save.

## Drift prevention
No theme editor, UI skin package, print system, report designer, or paid UI suite.

## Mandatory completion evidence
- Add/update automated tests for the change.
- Run Debug and Release build/test commands.
- Create the required development report under `docs/task-reports/`.
- Do not start the next task until the paired testing task has passed.
