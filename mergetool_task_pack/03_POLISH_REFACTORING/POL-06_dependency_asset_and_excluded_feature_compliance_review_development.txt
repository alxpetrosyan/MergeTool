# POL-06 Development Task
## Headline
Review dependencies, assets, and excluded-feature compliance


## Objective
Verify commercial readiness and prevent scope/licence drift.

## Developer instructions
Audit direct/transitive packages, package lock data, copied snippets/assets/fonts, build tools, and docs. Update dependency record with exact versions/licences. Verify explicitly that excluded features remain absent: automatic merge/sync, binary/image/Office/PDF/patch/VCS integration, reports/archive/audit, printing, cross-platform UI, installers/updaters/licensing.

Check for Araxis-originated assets/text/behavior copied verbatim; remove anything questionable.

## Drift prevention
This is compliance review, not legal advice or a new feature task.

## Mandatory completion evidence
- Add/update automated tests for the change.
- Run Debug and Release build/test commands.
- Create the required development report under `docs/task-reports/`.
- Do not start the next task until the paired testing task has passed.
