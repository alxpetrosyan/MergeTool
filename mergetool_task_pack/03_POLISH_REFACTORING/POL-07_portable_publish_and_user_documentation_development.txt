# POL-07 Development Task
## Headline
Prepare portable Windows publish and user documentation


## Objective
Enable controlled user testing without an installer, updater, or licence system.

## Developer instructions
Create reproducible `publish-portable.ps1` using `dotnet publish` for Windows x64. Document runtime/self-contained decision and output contents. Include dependency notices, user quick start, full user guide, troubleshooting, known limitations, and release checklist. Publish to `artifacts/` and test on a clean compatible Windows environment if available.

## Drift prevention
No MSI/MSIX installer, auto-updater, activation, online account, website, or telemetry.

## Mandatory completion evidence
- Add/update automated tests for the change.
- Run Debug and Release build/test commands.
- Create the required development report under `docs/task-reports/`.
- Do not start the next task until the paired testing task has passed.
